# UI SFX library (CC0)

Sound files copied from the open-source `uisfx` package (v0.4.0, https://uisfx.com, https://github.com/romainsimon/uisfx).
The audio is released under CC0 1.0 (public domain): commercial use is fine, no attribution needed (see LICENSE-AUDIO).
12 packs (arcade, cinematic, dreamy, glass, mechanical, minimal, organic, rubber, scifi, soft, studio, zen), 44 cues each (a selection of the 78 in the package). `cues.json` has each cue's recommended volume.
The studio picks a pack for each style (plan key `"sfx"`: `auto`, `synth`, or a pack name). See docs/sound.md.
